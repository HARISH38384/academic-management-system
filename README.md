# 🎓 Academic Management System

A modern, responsive, and feature-rich Academic Management System built using Django. This web application helps educational institutions efficiently manage students, teachers, departments, courses, attendance, examinations, marks, timetables, announcements, and reports through a centralized platform.

---

## 📌 Project Overview

The Academic Management System is designed to simplify academic administration by replacing manual processes with an organized digital solution. It provides administrators and faculty with powerful tools to manage institutional data, monitor academic performance, generate reports, and improve overall operational efficiency.

The application features a clean dashboard, responsive user interface, interactive charts, secure authentication, and an intuitive user experience suitable for schools, colleges, universities, and training centers.

## 🚀 Installation

### Clone the Repository

```bash
git clone <repository_url>
```

### Navigate to Project

```bash
cd academic_management
```

### Create Virtual Environment

```bash
python -m venv myenv
```

### Activate Environment

Windows

```bash
myenv\Scripts\activate
```

Linux / macOS

```bash
source myenv/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Apply Migrations

```bash
python manage.py makemigrations
python manage.py migrate
```

### Create Superuser

```bash
python manage.py createsuperuser
```

### Run Server

```bash
python manage.py runserver
```

Open your browser:

```
http://127.0.0.1:8000/
```
